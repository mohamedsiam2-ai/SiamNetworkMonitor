# Siam Network Monitor v18.0.0

Stable Windows release with the resizable taskbar meter, application traffic history, per-application charts, application identity, configurable alerts, data limits, connection intelligence, historical charts, diagnostics export, and consolidated settings.

## Build

Run `BUILD-AND-RUN.cmd` for a local Release build or `Publish-v18.0.0.ps1` to create the clean win-x64 GitHub release ZIP and `SHA256SUMS.txt`.

## Requirements

- Windows 10 or Windows 11
- .NET 8 Desktop Runtime for the framework-dependent release package
- Administrator approval for ETW per-process traffic capture
