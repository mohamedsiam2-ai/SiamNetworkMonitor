# Choose a license before publishing

No license was selected automatically because this affects how others may use the project.

Common choices:

- **MIT**: short and permissive; allows commercial reuse with attribution.
- **Apache-2.0**: permissive plus an explicit patent grant.
- **GPL-3.0**: derivative distributions must remain open source under GPL terms.
- **Private / no license**: public source is visible, but reuse permission is not granted.

After choosing, add the official license text as a root-level file named `LICENSE` and update the README License section.
