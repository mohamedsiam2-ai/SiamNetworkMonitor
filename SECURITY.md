# Security policy

## Supported version

Security fixes are targeted at the latest release only.

## Reporting a vulnerability

Do not publish credentials, executable paths containing personal information, usage-history files, or exploit details in a public issue. Use GitHub private vulnerability reporting if enabled for the repository. Otherwise, contact the repository owner privately.

Include the affected version, Windows version, reproduction steps, expected result, actual result, and any relevant `app-error.txt` content after removing personal paths and process data.
